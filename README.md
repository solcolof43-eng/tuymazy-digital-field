# Туймазинское месторождение — цифровая 3D-модель

Интерактивное веб-приложение: модель открывается по ссылке в браузере, без установки.

**Открыть:** https://solcolof43-eng.github.io/tuymazy-digital-field/

## Что внутри
- Реальный рельеф (Copernicus DEM GLO-30) и спутниковый снимок Sentinel-2 под всей площадью месторождения.
- Подземный блок: все горизонты от пермских отложений до фундамента, с изгибами, разломами и ВНК; каждый пласт подписан простыми словами.
- Срезы по X / Y / глубине и по линии профиля, изоляция и прозрачность пластов, разнос пластов, вертикальный масштаб.
- Карточка точки: кровля, подошва, эффективная толщина, насыщение, ФЕС, давление, ближайшие скважины.
- Скважины по статусам, ползунок времени (добыча, подъём ВНК), частицы притока и закачки.
- Режим «Бурение»: щелчок по местности ставит буровую, проходка показывает, какие пласты проходит долото и где оно входит в нефтяной пласт.
- Сценарии ГРП, полимерного заводнения, ЗБС. Метки обсуждения и ссылка на ракурс («Поделиться видом»).
- Ролик с бурением (кнопка «▶ Ролик»).

## Структура
- `index.html` — всё приложение (three.js 0.169 с CDN).
- `data/` — рельеф, снимок, карта, каротаж; `tex/` — текстуры (Poly Haven, CC0); `media/` — ролик.

Привязка координат ориентировочная; геологический разрез — схема по атласу месторождения.
